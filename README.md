# 🌱 Projeto Agrinho - AgroDiagnóstico (Análise Ecológica de Doenças)

Este é um projeto escolar interativo desenvolvido para o projeto Agrinho, focado em unir tecnologia e sustentabilidade no campo. O objetivo principal é fornecer uma ferramenta simples e acessível para que os agricultores possam diagnosticar problemas nas suas plantações e encontrar soluções e tratamentos ecológicos.

Todo o processo de desenvolvimento e hospedagem foi feito diretamente no **GitHub**.

---

## 📝 O que é o AgroDiagnóstico?

A identificação precoce de doenças e pragas nas plantas evita a perda de colheitas e reduz drasticamente a necessidade de aplicar agrotóxicos agressivos, promovendo um ecossistema mais equilibrado e saudável.

O AgroDiagnóstico atua como um assistente digital de bolso. Ao cruzar a informação da cultura cultivada com o sintoma visual observado (como manchas, pó nas folhas ou furos), o sistema sugere a causa mais provável e, o mais importante para a agricultura sustentável: fornece uma alternativa de tratamento orgânico e natural.

## 🚀 Funcionalidades do Mini Aplicativo

O site possui um simulador prático focado na realidade da lavoura e na rapidez da informação:

1. **Seleção da Cultura:** O utilizador indica o tipo de plantação que está a cultivar (Soja, Hortaliças, Milho, etc.).
2. **Análise de Sintomas:** O utilizador relata o que está a observar fisicamente na planta (ex: pó branco, folhas roídas, amarelecimento).
3. **Diagnóstico e Tratamento Ecológico:** O sistema identifica o problema (Fungos, Pragas, Deficiência Nutricional) e gera instantaneamente uma receita de maneio sustentável (ex: Calda de Leite, Óleo de Neem, Calda Bordalesa).

## 🛠️ Tecnologias Utilizadas

Para garantir a simplicidade e a viabilidade do projeto, utilizamos apenas as tecnologias fundamentais do desenvolvimento web:

* **HTML:** Estruturação semântica do site e do formulário interativo de diagnóstico.
* **CSS:** Estilização responsiva com uma paleta de cores voltada para a saúde vegetal, garantindo boa leitura ao ar livre.
* **JavaScript:** Lógica de cruzamento de dados (cultura + sintoma) para gerar o diagnóstico correto e as respetivas receitas ecológicas na interface.
* **GitHub e GitHub Pages:** Versionamento de código e hospedagem gratuita do site diretamente pelo navegador.
